# CP Tech concept-graph wiki — staging site (GitHub Pages bundle)

This directory is a **pre-built, self-contained static site**: one HTML page per concept,
a landing `index.html`, and a sibling `assets/` folder of images. There is no build step
and no runtime server. Every page renders fully offline with no external resource loads.

This is the **staging** build: the concept-graph–enriched pages (typed `parent_relation`
edges surfaced in the meta, plus grounded passages) rendered back into the tier-05 sidebar
HTML, generated by `output_builder_md_html.py` from `hierarchy_v2/13-concepts-graph-pages/`.
It deploys independently of the production wiki at
<https://github.com/ig0r/cnrt-pvmt-wiki>.

Live: <https://ig0r.github.io/cnrt-pvmt-wiki-stage/>

## Local preview

Serve this directory over HTTP and open <http://localhost:8000/>:

```
python -m http.server -d . 8000
```

## How it deploys

On every push to `main`, `.github/workflows/pages.yml` uploads this directory and deploys
it to GitHub Pages (Actions build type; self-enabled on first run). `.nojekyll` disables
Jekyll so directories/files beginning with an underscore and the raw HTML are served
verbatim.

## Re-syncing a fresh build

From `llm-wiki-tools/`, regenerate the site and mirror it here (scaffolding preserved):

```
uv run output-builder/output_builder_md_html.py --clean
rsync -a --delete \
  --exclude='.git' --exclude='.github' --exclude='.nojekyll' --exclude='README.md' \
  hierarchy_v2/13-concepts-graph-pages-html/ ../../cnrt-pvmt-wiki-stage/
git -C ../../cnrt-pvmt-wiki-stage add -A && \
  git -C ../../cnrt-pvmt-wiki-stage commit -m "Update staging build" && \
  git -C ../../cnrt-pvmt-wiki-stage push
```
